### 2. Create presenter layer

File: `apps/web-vue/src/presenters/product.presenter.ts`

Maps API `Product` → `ProductPresenter`:

```typescript
interface ProductPresenter {
  name: string // from API name
  title: string // framework label (Vue/Angular/React/Svelte)
  description: string // mocked tech description
  logo: string // icon name for the tech
  previousPrice: number
  price: number // always 0
  rate: number // 1-5
}
```

Presenter is pure TS, no Vue deps.
