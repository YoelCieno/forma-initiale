# 2.6 Product Integration

## Goal

Transform `ProductsPage` into a product showcase using the updated domain model, a presenter layer, WA card components, and a responsive grid layout.

## Tasks

### 1. Update Product domain model

| Change | Current | New |
|--------|---------|-----|
| Rename field | `title: string` | `name: string` |
| Add field | — | `previousPrice: number` (takes current `price` value) |
| Reset field | `price: number` (varies) | `price: 0` |
| Add field | — | `rate: number` (1-5) |

Files to update:
- `packages/domain/src/models/Product.ts`
- `packages/infra/src/mocks/factories/product.ts` — produce new shape
- `packages/infra/src/mocks/handlers/products.ts` — include new fields
- `packages/infra/src/adapters/` — DTO if needed
- All tests referencing old `title`/`price`

### 2. Create presenter layer

File: `apps/web-vue/src/presenters/product.presenter.ts`

Maps API `Product` → `ProductView`:

```typescript
interface ProductView {
  name: string        // from API name
  title: string       // framework label (Vue/Angular/React/Svelte)
  description: string // mocked tech description
  logo: string        // icon name for the tech
  previousPrice: number
  price: number       // always 0
  rate: number        // 1-5
}
```

Presenter is pure TS, no Vue deps.

### 3. Build fe-card wrapper

File: `packages/ui/components/fe-card.ts`

hybridJS wrapper composing `<wa-card>`:
- Re-export WA card API — slots: `header`, `footer`, `media`, `actions`, `footer-actions`, `header-actions`
- Props: `appearance`, `orientation`
- See WA card ref: `.opencode/references/webawesome/references/components/card.md`

### 4. Refactor ProductsPage

Replace flat list with `<fe-card>` grid:
- Each card: media (logo), header (title + framework name), body (description, rating, pricing)
- Grid: CSS `column-count` responsive (1→2→3 at breakpoints via `@container` queries)
- Reference: https://webawesome.com/examples/themes/showcase

### 5. Update tests

- ProductsPage spec — card grid rendering
- useProducts spec — new shape
- presenter spec (new) — pure TS unit tests
- Factory tests — new `name`, `previousPrice`, `price`, `rate`

### 6. BEM CSS

Card grid styles use BEM:
- `.products-page__grid` — responsive container
- `.products-page__card` — individual card
- `.products-page__card-image` — media area
- `.products-page__card-title` — framework name
- `.products-page__card-description` — tech description
- `.products-page__card-price` — pricing section
- `.products-page__card-rating` — star rating

## Dependencies

- fe-card component must exist first
- fe-icon component must exist first (for logos)
- Updated Product domain model must deploy first

## Test expectations

- Presenter: 100% coverage (pure mapping fn)
- ProductsPage: integration test for card grid rendering
- fe-card: spec following fe-button pattern (shadow DOM, property forwarding, slots)
