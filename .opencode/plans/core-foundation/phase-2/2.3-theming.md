# 2.3 Theming / Design Tokens — IMPLEMENTED

Web Awesome exposes all visual properties as CSS custom properties prefixed with `--wa-*`. This makes theming straightforward: override the variables at any CSS cascade level.

## Implementation

The theme system is now live across three layers:

### Layer 1: WA Base (`packages/ui/styles/webawesome.ts`)

Imports `native.css` + `utilities.css` — theme-agnostic reset and utility classes. **No theme CSS** is bundled here.

### Layer 2: WA Theme (`packages/ui/styles/themes/<name>`)

Each app imports a separate theme file:

- `default.ts` → WA default theme (used by `web-vue`)
- `awesome.ts` → WA awesome theme (reserved for `white-label-angular`)
- `shoelace.ts` → WA shoelace theme (reserved for `web-react`)

Exposed via `@repo/ui/styles/themes/<name>` exports in `package.json`.

### Layer 3: DS Tokens (`apps/*/src/styles/tokens.css`)

App-level `--wa-*` CSS custom property overrides for:

- **Brand colors**: indigo palette (`--wa-color-brand-fill-*`, `--wa-color-brand-border-*`, `--wa-color-brand-on-*`)
- **Typography**: Inter heading/body + JetBrains Mono code (`--wa-font-family-*`)
- **Border radius**: s/m/l scale (`--wa-border-radius-*`)

### Theme activation

The `<html>` element in `apps/web-vue/index.html` has class `fe-theme-default fe-palette-default fe-brand-blue`.

Import order in `main.ts`:

```typescript
import '@repo/ui/styles' // Layer 1: WA base
import '@repo/ui/styles/themes/default' // Layer 2: WA theme
import './styles/tokens.css' // Layer 3: DS overrides
```

## Token strategy (future work)

- **Per-component overrides** — Vue SFCs can scope token overrides via `scoped` styles: `:deep(fe-button) { --wa-button-border-radius: var(--radius-sm); }`. Not yet used.
- **Dark mode** — `.fe-dark` / `.fe-invert` selectors for color-scheme toggling. Not yet implemented.

WA components that ship their own shadow DOM styles are encapsulated; overrides require CSS custom properties (the `::part()` pseudo-element is also available for specific internal elements WA exposes).
