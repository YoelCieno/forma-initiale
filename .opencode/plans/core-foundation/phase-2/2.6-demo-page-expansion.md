# 2.6 Demo Page Expansion

## Goal

Expand DemoPage with fe-icon, fe-rating, and fe-card showcases. Apply CSS UX polish (font-size scale, semantic colors). Replace wa-icon usage in fe-button with fe-icon.

## Tasks

- [x] CSS UX polish — define font-size scale (`--fs-xs` through `--fs-xl`), semantic colors (`--color-text-body`, `--color-text-muted`, `--color-border-light`, `--color-error`), uncomment WA typography tokens in `base.css`
- [x] Replace hardcoded colors in App.vue and ProductsPage.vue with CSS var references
- [x] Create fe-card component (`packages/ui/components/fe-card.ts`) — thin re-export via WC subclass (FeCard extends WaCard), not hybridJS, because WaCard already registered
- [x] Add fe-card spec — 6 tests: registration, shadow DOM, default appearance, orientation, header slot, footer slot
- [x] Add fe-icon demo section to DemoPage — basic icons, animated icons, size variants
- [x] Add fe-card demo section to DemoPage — appearances, slots (media, header, body, footer), horizontal orientation
- [x] Update fe-button to use `<fe-icon>` internally instead of `<wa-icon>`
- [x] Configure ESLint to allow `slot` attribute on WC elements
- [x] fe-rating component (`packages/ui/components/fe-rating.ts`) — hybridJS wrapper over `<wa-rating>`, 23 tests, 9 props forwarded
- [x] Add fe-rating demo section to DemoPage — basic, value, readonly, disabled, max, precision, sizes

## Key Decisions

| #   | Decision           | Choice                                  | Rationale                                                                                   |
| --- | ------------------ | --------------------------------------- | ------------------------------------------------------------------------------------------- |
| 1   | fe-card impl       | WC subclass (extends WaCard)            | WaCard already registered CE — subclass for new tag name, hybridJS cannot override existing |
| 2   | fe-rating impl     | hybridJS                                | wa-rating not registered by default, hybridJS `define()` for property forwarding            |
| 3   | CSS color approach | Semantic CSS vars                       | `--color-text-body` replaces inline `gray-700`, themeable per app                           |
| 4   | ESLint slot rule   | `vue/no-deprecated-slot-attribute: off` | WC slot attr use is correct per spec, Vue deprecation warning is false positive for WC      |
| 5   | WA attr reflection | Use `Reflect.get()` in tests            | WA components don't reflect boolean/string props to attrs                                   |
