## Decisions (explore session 2026-10-11)

- **Templates layout** — flat files `packages/generator/src/templates/{vue,angular,common}.ts` (revised 2026-10-25: folder + `index.ts` per framework rejected in favour of sibling files); Vue strings + spec move to `templates/vue.ts`, shared strings (`tokensCss`, `metadataTs`, `gitkeep`) live in `templates/common.ts`. Static templates (no `ctx` interpolation) are plain `string` constants passed straight to `renderTemplate` — pinion `getCallable` accepts non-function values, so no more `(_ctx) =>` wrappers + `eslint-disable` noise.
- **Metadata = infra (decision W1)** — fixture metadata generates into `packages/infra/src/metadata/<name>.ts` + barrel export line appended to `packages/infra/src/index.ts` (precedent: register-tenant already mutates `packages/infra/src/mocks/data/mocked-data.json`). Keys = `${name}-alpha/beta/gamma` — current template strips the last name word so keys NEVER match MSW product ids (dead metaMap). Idempotent: file exists → skip write, only ensure barrel line; curated `fake-plants.ts` MUST never be overwritten. Tenant `main.ts` imports `<camel>Map` from `@repo/infra`; template `package.json` gains `@repo/infra`; app-root `metadata.ts` generation deleted.
- **Ports** — Angular dev ports live in `angular.json` `serve.options.port` (3200 white-label / 3201 fake-plants — moved off `--port` flags in package.json). Angular port allocator scans `apps/*-angular/angular.json`.
- **appShell** — default = shell root `<app-root>`; prompt opt-in tenant appShell → selector `<{prefix}-root>` + matching `src/index.html` host tag (else NG05104).
- **Pre-hooks** — generated Angular tenant wires `predev`/`prebuild`/`pretest` running `bun scripts/gen-component-overrides.ts` (`bun run` executes pre/post, fails-closed: failed pre-hook aborts main script).
- **No vitest.config in Angular tenant** — test config lives in angular.json `test` target (`@angular/build:unit-test` + element-internals `setupFiles`). Plan's earlier "vitest config" line was a Vue copy-paste.
- **MSW** — worker file stays plain cp (byte-identical, framework-agnostic); only paths get de-hardcoded. Regen-all-apps command = PENCIL (see 4.7.2).
